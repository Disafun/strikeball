# Страйкбол-клуб (Flask + Supabase)

Игроки и администратор работают с одними и теми же данными: профили, мероприятия, записи,
альбомы и фото лежат в облаке Supabase (PostgreSQL + Storage). На устройстве остаётся только
cookie с сессией входа. Требуется **Python 3.11+**.

## Архитектура

```
Браузер (телефон/ПК)  ──►  Flask-приложение  ──►  Supabase
                                                    ├─ Auth      (почта + пароль)
                                                    ├─ Postgres  (таблицы + RLS + триггер вместимости)
                                                    └─ Storage   (bucket "photos")
